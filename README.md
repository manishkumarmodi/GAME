# Eye

A single-page demo that renders two stylized eyes which blink and track the cursor with a glowing red pupil effect.

## Features
- Cursor tracking: pupils move toward the pointer using simple trigonometry.
- Blinking animation: periodic vertical squish gives a natural blink.
- Flicker text: heading uses a flicker animation for a surveillance vibe.
- Lightweight: pure HTML, CSS, and vanilla JavaScript in one file.

## Run locally
1. Open `eye.html` in any modern desktop browser.
2. Move your cursor to see the pupils follow and the hover glow intensify.

## File structure
- `eye.html` — self-contained page with styles, markup, and script.

## Customization
- Color: edit the red values in the CSS for a different theme.
- Size: adjust `.eye` width/height and `.pupil` size for larger or smaller eyes.
- Blink speed: tweak the `blink` keyframes duration to change blink frequency.
